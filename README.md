# Money Ideas (أفكار المال) 💡💰

تطبيق متكامل لربط رواد الأعمال والمستثمرين والشركات مع منظومة ذكية لتوليد ودراسة أفكار المشاريع وتحليل الجدوى والمخاطر.

---

## 📱 ميزات التطبيق (Features)

- **نظام حسابات متعدد الأدوار**: مستثمر، رائد أعمال، شركة، موظف/باحث عن فكرة.
- **محرك تحليل ومطابقة ذكي**: مطابقة الأفكار مع الميزانية والخبرة والأهداف الاستثمارية.
- **قاعدة بيانات Supabase**: توثيق RLS كامل وسياسات أمان متقدمة ودعم Realtime Chat.
- **تصميم عصري Material 3**: دعم كامل للغتين العربية والإنجليزية مع دعم الوضع المظلم (Dark Mode).
- **دعم العمل دون اتصال (Offline-first)**: تخزين مؤقت محلي وسريع باستخدام Hive.

---

## 🚀 البناء التلقائي عبر GitHub Actions (CI/CD)

يحتوي المستودع على إعدادات **GitHub Actions** لبناء نسختي التطبيق تلقائياً عند كل Push أو Release:

1. **نسخة أندرويد (Android APK)**:
   - يتم بناؤها وتوليد ملف `moneyideas-release.apk`.
   - متاحة للتحميل المباشر من تبويب **Actions -> Artifacts**.

2. **نسخة آيفون (iOS IPA)**:
   - يتم بناؤها وحزمها كملف `moneyideas-release.ipa` (Unsigned).
   - يمكن تثبيتها وتجربتها عبر أدوات التحميل الجانبي (مثل AltStore أو Sideloadly) أو توقيعها للنشر.

### 📥 كيفية تحميل النسخ من GitHub:
1. اذهب إلى تبويب **Actions** في صفحة المشروع على GitHub.
2. اضغط على آخر تشغيل ناجح للـ Workflow (`Build & Release Mobile Apps`).
3. ستجد في أسفل الصفحة قسم **Artifacts**:
   - `moneyideas-android-apk` (ملف APK للأندرويد).
   - `moneyideas-ios-ipa` (ملف IPA للآيفون).
4. أو عبر قسم **Releases** عند إنشاء إصدار جديد (Tag).
